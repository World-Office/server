# P2-02 — Rust: extract Shaper + shaped-run line breaking (Phase B), replaces char_advance

Implements PORT-PLAN Phase 2 item 2 (ORM-04 shaping capability), first half:
extract a `Shaper` out of `Canvas::draw_text` and add the
`wo-renderer::shaping` + `wo-renderer::textlayout` modules so that line
breaking runs on **shaped runs** instead of the legacy per-character
`FontLibrary::char_advance` estimate. No wasm signature changes (per the
plan).

## What landed

| piece | what it is |
|---|---|
| `shaping::Shaper` | rustybuzz shaper bound to one font face; owns the font data, exposes `from_font_data` / `from_library(lib, bold)` (same face selection as `draw_text`), `shape(text, font_size) -> ShapedRun` (positions pre-scaled to pixels), `advance(text, font_size)`, `units_per_em` / `font_data` / `face_index` accessors. Latin v1: no features, no ligatures, no bidi — glyph *i* corresponds to char *i* (same contract the old inline `draw_text` code had). |
| `shaping::ShapedRun` / `ShapedGlyph` | positioned glyphs in pixel space; each glyph carries `is_space` (shaped from a whitespace source char) — the break signal for line breaking. `width()` / `position_at(i)` helpers. |
| `textlayout::break_lines(run, max_width) -> Vec<LineBreak>` | greedy shaped-run line breaking: words (maximal non-space spans) kept whole, break at whitespace positions, break **consumes** its separating space(s) (no leading/trailing spaces on a line — matches the legacy output exactly). A word wider than `max_width` on an empty line is forced, never split (legacy contract, pinned by `test_break_lines_long_word_not_broken`). |
| `textlayout::layout_paragraph(shaper, text, font_size, max_width, line_height) -> Vec<ShapedLine>` | paragraph driver: `\n` forces a break, blank lines produce nothing and do not advance the origin, whitespace runs normalize to single spaces; each physical line is shaped then broken. Line `y = line_index * line_height`; the caller adds ascent for baselines. |
| `text::TextLayoutEngine` rewiring | `layout_paragraph` now routes through `Shaper` + `textlayout::layout_paragraph` whenever the library yields a usable face (the public API and `TextLayout`/`TextLine` shapes are unchanged); the old per-character loop is kept verbatim as `layout_paragraph_fallback` for the no-font case (e.g. `FontLibrary::empty()` unit tests). |
| `canvas::draw_text_weighted` refactor | the inline rustybuzz block (face creation, unicode buffer, scale factor) is replaced by `Shaper::from_library` + `Shaper::shape`; the swash rasterization loop now walks `ShapedRun` glyphs with pre-scaled positions. Pixel-identical math (`x_offset * unit_scale` computed once inside the shaper). |
| `shaping_tests.rs` | 25 tests: deterministic `break_lines`/`ShapedRun` tests on hand-built runs (wrap-at-space with break-space consumption, zero-width forced first word, long-word-not-split, leading/trailing/consecutive spaces, slice/width), `Shaper` construction (invalid data, empty library), and system-font-shape tests (`shape` ASCII 1:1, space detection, empty string, advance ∝ font size, paragraph wrapping/blank-line contract, `TextLayoutEngine` shaped-path end-to-end incl. width == shaped advance and baseline stepping). System-font tests use the `canvas.rs` environment-skip idiom. |
| ORM-04 ledger | `engine-internals.json` `fontengine/TextShaper.h` row notes updated (severity stays 1 — see below); `orm04-build.cjs` SPEC updated in lockstep so regeneration keeps the new note. |

## Deliberate non-changes

* **`FontLibrary::char_advance` stays** — `wo-renderer-wasm/src/layout.rs`
  (out of this task's file scope) still measures with it, and the
  no-font fallback in `TextLayoutEngine` uses it by design. "Replaces
  char_advance" holds for the wo-renderer layout path: with a font loaded,
  no `char_advance` call participates in line breaking anymore.
* **No bidi** — the plan names bidi segmentation consuming "the existing
  wo-unicode tables"; `wo-unicode` currently has no bidi table (only
  converter/encoding/normalizer), so v1 breaking is LTR, matching the
  existing Latin-only `draw_text` contract. Flagged as follow-up.
* **Kerning/ligatures/features** still off (empty feature list, same as
  before) — ORM-04 `GlyphString.h` row stays sev 3 on that basis.
* **Wasm signature changes: none**, per the plan.
