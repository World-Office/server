# P3-U03 — JS: ShapeSettings + ReviewPopover + ExtendedColorDialog from the engine

Third (and last planned) consumer batch of the P3-U01 data-driven dialog
engine: three more OO views from the ORM-09 missing backlog are hosted as
DIALOG SPECS in `wo-dialogs.js` with the behavioral half in editor.js — the
same split P3-U02 used for TableSettingsAdvanced/ImageSettingsAdvanced.

## What landed

|---|---|

## Deliberate non-changes

* **Pattern/image fill** — the OO fill registry (fill patterns, picture
  fills, theme fill references) has no WO object-model counterpart; the spec
  exposes exactly the three kinds WO can render (none/solid/gradient) and
  the ledger note says so.
* **Gradient fill is a CSS approximation** — `linear-gradient` on the shape
  wrapper (the svg interior stays transparent so it shows through), not an
  OOXML `<a:gradFill>` writer. Same policy as P3-U02's crop/adjust; a real
  gradient model belongs to the shape/serialize layer, not the dialog.
* **Shadow is box-shadow** — OO's `asc_CShadowProperty` (direction/distance/
  blur/alRadial styles) collapses to offset/blur/color here.
* **ReviewPopover is an engine modal, not a floating widget** — it keeps the
  modal conventions (DIALOG_IDS Esc/Tab trap, ledger entry per apply) and is
  only *anchored* at the comment; no per-reviewer colors/avatars, no
  reply-timestamp rendering (WO's comment model has no timestamps).
* **ExtendedColorDialog has no HSB wheel and no recent-colors memory** — the
  P3-U01 picker is slider-based (same as the widget row says); wheel +
  palette memory would be new widget work, noted in the ledger row.
