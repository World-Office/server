# ORM-06 — OO XlsxFormat C++ → wo-sheet coverage map

Spreadsheet-converter counterpart to `ooxml-docx.md`: every class family of
OnlyOffice's `XlsxFormat` C++ (Euro-Office `core/OOXML/XlsxFormat/`) judged
against what this worktree's `wo-sheet` crate (and its companions
`wo-ooxml`, `wo-chart`, `wo-x2t`) actually implements, so the Rust path can
reach 1:1 workbook read/write.

## Per-subdir map with WO verdict

### root — container, flat format, base types → PARTIAL

`CXlsx` zip container, `FileTypes_Spreadsheet` dispatch and `CRelationShip`
are covered by wo-x2t router + wo-ooxml parser/serializer. The **flat
SpreadsheetML 2003 readers (`CXlsxFlat`, flat `CWorkbook`/`CWorksheet`) are
missing entirely** — only ZIP xlsx opens. `WritingElement`/`ComplexType`
plumbing is intentionally replaced by serde derives (no action needed).

### Workbook → PARTIAL

`CWorkbook`, `CSheets`, `CWorkbookPr`, `CBookViews`, `CDefinedNames`,
`CCalcPr` map onto `wo-sheet::model::Workbook` + the `Xlsx*` structs with
gaps (workbook protection, file sharing, window geometry, iterate calc,
built-in names). **Missing:** `CWorkbookProtection`, `CMetadata/CMdx*`,
`CDynamicArrayProperties` (spill formulas), `CRichValueBlock`,
`CWorkbookPivotCaches`, XML maps. Dynamic arrays matter: a modern workbook
with `SORT`/`FILTER` formulas degrades silently.

### Worksheets → PARTIAL (the heart of the converter)

Solid: cells/rows (`CRow/CCell/CSheetData`), cols, merges (the only clean
`full` in the tree besides styles alignment), freeze panes, sheet visibility,
sheet protection (SHA-256 hashed password in `SheetProtection`), user
protected ranges (`EditRange` + `is_edit_allowed_for_user`), data validation
(7 types × 8 operators × 3 error styles), 13 conditional-format rule kinds,
sort ops. **Missing:** hyperlinks (`CHyperlinks` — grep finds zero hyperlink
support), sparklines (`CSparklineGroup`), `CColorScale`/`CDataBar`/`CIconSet`
conditional formats, the whole print model (`CPageSetup`, `CPageMargins`,
`CPrintOptions`, `CHeaderFooter`, `CRowColBreaks`), cell watches, data
consolidation, per-view selection.

### Styles → PARTIAL

Fonts/fills/borders/numFmts/xf chains exist in `XlsxStyles` and are
regenerated by the serializer; alignment + protection structs are 1:1.
**Missing:** `CDxf/CDxfs` (needed by CF + tables), `CCellStyles` (named
styles), `CColors/CIndexedColors` (legacy palettes render wrong),
`CGradientFill`, `CTableStyles`, rich `CRPr`. Number-format *rendering*
(`format.rs`) covers only a subset of Excel codes.

### SharedStrings → PARTIAL

`Vec<String>` both in `XlsxWorkbook.shared_strings` and
`WoSpreadsheet.sharedStrings`. Rich runs (`CRun`), phonetic runs (`CRPh`,
CJK furigana) and phonetic properties are flattened away.

### CalcChain → MISSING

No calc-chain model; `formula_eval.rs` recomputes everything on load —
semantically safe, slower on 1M-cell books. Low priority; it is a
performance hint, not data.

### Chart → MISSING (174 classes, biggest single gap)

`CChartFile/CChartSpace/CChartExFile/CChartStyleFile/CChartColorsFile`
survive only as opaque `extra_parts` blobs: a workbook containing a chart
**round-trips but shows no chart, and any edit drops nothing but also adds
nothing**. `wo-chart::model` (ChartKind: line/bar/pie/scatter/area families;
Axis; Legend; ChartTitle; ChartDataLabel) could host a real mapping but is
wired into **wo-slide** only — nothing converts XLSX chart XML into it.
Unrepresented even in wo-chart: trendlines, error bars, 3D, bubble, radar,
surface, stock, doughnut/of-pie, multi-level categories, pivot-chart
linkage, per-chart page setup.

### Drawing → PARTIAL (x2t only)

`CDrawingWorksheet` parts are preserved byte-faithfully; anchors (`CCellAnchor`,
EMU `CFromTo/CExt`) and `CClientData` (shape-to-cell formulas) are unmodeled —
wo-sheet has no floating-object layer at all.

### Comments → PARTIAL (x2t only)

Legacy `CComments`/VML preserved as blobs; no comment model in the sheet path
(note: *Word* comments do have a model in wo-ooxml). Modern threaded comments
(`CThreadedComments`, `CPerson`, mentions) fully missing.

### Controls / Ole → MISSING

Form controls (`CControl`, `CFormControlPr`) and OLE objects absent;
interactive sheets (checkbox/spinner/list) degrade to static cells.

### ExternalLinks → MISSING

`CExternalLink/CExternalBook/CExternalSheetData/CExternalDefinedName` and
DDE/OLE links: not parsed; formulas referencing other workbooks fall back to
errors after a WO edit round-trip.

### Pivot → PARTIAL (engine yes, file model no)

`wo-sheet/pivot.rs` is a real pivot *engine*: `PivotTableConfig`
(row/col/value/filter fields, grand totals), 11 `AggFunc` consolidations
(Sum…VarP), `PivotEngine::create_pivot` over source data. But it never reads
or writes the pivot parts: `CPivotCacheDefinition` (cacheFields/sharedItems),
`CPivotCacheRecords`, grouping (`CGroups/CGroupLevels`), calculated items,
`CPivotTableStyleInfo`, pivot areas, OLAP hierarchies/measures are missing —
a pivot table built in Excel reappears as plain values.

### RichData → MISSING (all 17 classes)

`CRichValueData`, structures, types, keys: linked data types (stocks,
geography) and images-in-cells have no representation at all; cells fall
back to their cached fallback text.

### Slicer / Timelines / NamedSheetViews → MISSING

All 73 classes across these three subdirs lack any counterpart (slicers,
timeline caches, named sheet views). Preserved as blobs via x2t where they
are ZIP parts.

### Table (Excel tables / autofilter / query tables / connections) → MISSING

`CTable`, `CAutofilter` (+ all filter types), `CQueryTable`,
`CConnection`, XML mapping: absent. Consequence: structured references
(`Table1[Amount]`) cannot evaluate, and saved filter/sort UI state is lost.
`SheetOp::Sort` (op-level) is the only surviving sibling.

## Ranked missing features (what breaks without it)

1. **Chart model + xlsx chart parser → wo-chart** — books silently lose every
   chart; this is the largest class delta (174 OO classes).
2. **Excel tables + autofilter + structured references** — table formulas
   evaluate as errors; filtering state lost. 67 classes in `Table/`.
3. **Hyperlinks** — single most common interactive feature; currently dropped
   to text on import.
4. **Pivot file model (cache definition/records, grouping, calculated items)** —
   Excel pivots degrade to static numbers; the engine exists, the persistence
   doesn't. 92 classes.
5. **RichData (linked data types, images in cells)** — modern workbook content
   invisible. 17 classes.
6. **Conditional-format completeness (colorScale/dataBar/iconSet + dxf styles)** —
   dashboards render without the exact visual the author chose.
7. **Sparklines** — in-sheet mini charts lost (extLst part).
8. **External links** — cross-workbook formulas break after an edit.
9. **Print model (pageSetup/headerFooter/breaks)** — no print/PDF parity.
10. **Rich shared strings (runs, phonetic)** — per-run cell formatting and CJK
    furigana flattened.
11. **Workbook metadata: dynamic arrays, threaded comments, protection** —
    modern-formula and review workflows silently downgrade.
12. **CalcChain** — none needed for correctness (full recompute); only a
    large-book performance item.

## Recommended wo-sheet / ecosystem module additions

- `wo-sheet::chart_bridge` — parse `xl/charts/*` into `wo-chart::model::Chart`
  (which already renders via `render::render`) and attach per-sheet; extend
  `ChartKind` with radar/bubble/surface/stock + trendline/error-bar structs.
- `wo-sheet::table` — `ExcelTable {name, range, headerRowCount, totalsRow,
  styleInfo}` + autofilter state + structured-reference resolution in
  `formula_eval` (map `Table1[Col]` → `Range2d`).
- `wo-sheet::hyperlink` — `Hyperlink {cell, target, display, tooltip,
  location}` on `Sheet` + click routing in ops.
- `wo-sheet::pivot_file` — serde structs for `pivotCacheDefinition` /
  `pivotCacheRecords` / `pivotTableDefinition` feeding the existing
  `PivotEngine` (engine unchanged); add grouping + calculated items.
- `wo-sheet::rich_text` — `RichString {runs: Vec<Run>}` behind `Cell`,
  replacing the `raw: String` flattening; also carries phonetic runs.
- `wo-sheet::page` — pageSetup/pageMargins/headerFooter/breaks for print +
  PDF export parity with `wo-ooxml` docx path.
- `wo-sheet::cf_styles` — `ColorScale/DataBar/IconSet` rule variants + a dxf
  style table so conditional formats round-trip with styles.
- `wo-sheet::external` — external-link part model + resolution hook in
  `formula_eval`.
- Serializer work in `wo-ooxml`: extend `serialize_xlsx` beyond the current
  9 core parts so regenerated books keep charts/tables/hyperlinks instead of
  relying on `extra_parts` passthrough.

## Grounding cross-references

- x2t passthrough boundary: `wo-x2t/src/converters.rs`
  `collect_xlsx_extra_parts` (9 core parts regenerated; the rest — charts,
  pivot caches, drawings, comments/VML, externalLinks — as blobs, tagged
  F-200/206/207).
- The 42 `partial` rows converge on one theme: `wo-sheet::model::Cell` is a
  flat `{raw, value, formula, style}` engine cell, while OO's model is a
  nested OOXML document. Closing that gap is mostly *additive* (new optional
  fields/parts), not a rewrite — `SheetOp`, `formula_eval`, and the serde
  contract stay stable.
